# Memoryfield · Tesseract

Hari Seldon's Psychohistory Lens - Interactive 3D visualization of economic topology and field dynamics.

## Features
- 3D Tesseract (hypercube) visualization
- Economic node network with real-time correlations
- Psychohistory metrics (Coherence, Entropy, Persistence, Seldon Crisis)
- Interactive node selection
- Dynamic field evolution

## Tech Stack
- Three.js
- CSS2DRenderer
- OrbitControls
